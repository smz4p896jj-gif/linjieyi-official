林捷夷代表官方網站｜前台＋後台完整版

主要功能：
1. 民眾可在前台送出陳情資料。
2. 陳情資料直接儲存在網站 SQLite 資料庫。
3. 後台可查看全部案件。
4. 案件可標記：待處理、處理中、已完成。
5. 後台可發布／刪除最新消息。
6. 後台可更新服務電話、LINE、Facebook、服務處地址。
7. 後台可更新首頁主標、標語與介紹文字。
8. 後台可修改管理員密碼。
9. 第三選區目前包含：頂埔、石硦、同仁、灣潭、東興、中崙、澐水、三層、龍門、深坑、裕民、瑞豐。

預設管理員：
帳號：admin
密碼：12345678

正式上線後請第一時間修改密碼，並設定 SECRET_KEY。

本機或主機啟動：
pip install -r requirements.txt
python app.py

前台：http://127.0.0.1:5000
後台：http://127.0.0.1:5000/admin/login

正式部署可使用 Render、Railway、VPS 等支援 Python/Flask 的主機。
若正式公開收集民眾姓名、電話與陳情內容，建議同時加上 HTTPS、個資告知、備份與權限管理。
